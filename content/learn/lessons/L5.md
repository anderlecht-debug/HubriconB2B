## Returns Amazon damaged

When a return arrives, Amazon grades it. Some grades are your problem and some are Amazon's. On the demo catalogue {{rec_damaged_return_n}} returns worth {{rec_damaged_return_value}} were Amazon's.

### Where the row is

FBA Customer Returns, the column called detailed disposition. A disposition of {{dispositions_claimable}} means Amazon or its carrier damaged the unit after the customer sent it back, and that is a claim. A disposition of {{dispositions_not_claimable}} is customer damage, a defect, or expiry, and none of those is Amazon's liability. Sellable means the unit went back into your inventory and there is nothing to claim.

On the demo catalogue, {{rec_returns_sellable}} returns were sellable, {{rec_returns_customer_or_defective}} were customer damage or defective, and {{rec_returns_already_reimbursed}} damaged returns had already been paid. The claims are what is left.

### Already paid?

Check the status column on the return. If it contains the word reimbursed, Amazon paid. Check the Reimbursements report for the order id with a return or damage reason. Either one removes the candidate.

### The window

Eligible at once; there is no waiting period on a graded return. The window shuts {{win_damaged_deadline}} after the return date. These close fast, and the demo catalogue's soonest deadline at the time of the run was a {{rec_soonest_type}} claim with {{rec_soonest_days}} left.

### Value and odds

Landed cost per unit. Approval odds: {{p_approve_damaged_return}}, the lowest in this playbook, because Amazon will sometimes regrade the return on review. File anyway; the expected value is still positive on almost every row.

### How to file

Seller Support, Fulfillment by Amazon, then the customer return option, then a damaged return. Give the order id, the license plate number from the returns report, the SKU, the disposition Amazon itself recorded, and the return date. Ask for reimbursement at cost for a unit Amazon graded as damaged in its custody. Log the case.
