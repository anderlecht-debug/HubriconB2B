      Before you export: three things Shopify does

      1. Clear your filters first. An export sends what is on screen. With a search box, a status filter or a tag still applied, the CSV quietly contains that slice and nothing else.
      2. The file arrives by email, not in your browser. Any export you set a date range on — and any list longer than 50 rows — is emailed to you and to the store owner, usually within a couple of minutes. Nothing downloading on the page is normal. Go to your inbox.
      3. Send the .csv itself. Choose Plain CSV file when Shopify offers the choice. If what lands is a .zip, unzip it and upload the .csv inside.

      About ten minutes of clicking, and most of the wait is email.

      Orders — last 6 months

      Every order and line item. This is the sales, refund and discount history every model runs on, and six months is what lets us fit your trend and your season instead of photographing one week.

      What we read, and what we keep. Eleven columns: Name (the order number), Email, Financial Status, Created at, Cancelled at, Refunded Amount, and each line's sku, name, quantity, price and discount. Our database keeps a per-SKU total for each month, and one row per order: its number, date, units and revenue, with the customer's email turned into a one-way code (a SHA-256 hash of the address, keyed to your account). The same customer gets the same code on every order, so we can count who comes back without keeping the address. That matters for your ads: a customer worth three orders is worth more than one order's margin to win, so repeat value raises what an ad can afford (we count it once your orders hold a hundred customers and six months, and only where it predicts your own last quarter). Names, addresses and phone numbers are never read.

      The file itself is kept as you sent it, in your encrypted store, and deleted with the rest of your data when you ask. You may delete the name, address and phone columns before you upload: nothing reads them. You may delete the Email column too, and everything else still works, but repeat-customer value is then off and your ad break-even counts the first order alone.

      Shopify admin → Orders → clear any filters → Export → Orders by date → set the range → Plain CSV file → Export orders (not “Export transaction histories”).

      One file for all six months is ideal, and the dates below are already set. If your store is busy enough that the file comes back over 50 MB, export one month at a time and add a range here for each — six monthly files land exactly like one six-month file.

      Products & costs

      Today's export carries the one number no platform can work out for you: Cost per item. If that field is empty in Shopify, fill it in before you export — it is the difference between a margin and a guess. Ship from one location and this file is your stock snapshot too.

      Shopify admin → Products → Export → All products → Plain CSV file → Export products.

      Ship from more than one location? A 3PL plus your own shelf counts as two. Shopify prints stock quantities in this file only for single-location stores, so send the inventory export below as well.

      Inventory — only with 2+ locations

      One location? Skip this; your Products export already carried the stock. With two or more, Shopify prints no quantities in that file at all, and this is the only export that says what is really on the shelf — without it, reorder points, stockout risk and tied-up cash have nothing to run on. We sum your locations; the split is kept.

      Shopify admin → Products → Inventory → Export → All locations → Plain CSV file.

      Payouts

      The processing fees you actually paid, in place of the 2.9% + 30¢ estimate. That estimate is Shopify Payments' standard card rate on the Basic plan; on Grow, Advanced or Plus you pay less, so without this file your fees read high and your margin low on every SKU. Ninety days is enough.

      Shopify admin → Finances → Payouts → View transactions → Export → set the range → Plain CSV. (Same screen via Settings → Payments → View payouts → Transactions.)

      Only exists on Shopify Payments. On another processor there is no such export — skip the card and we use the published rate. It sits under Finances, which the seat we ask for cannot open, so this file always comes from you, here, including in later months.
